### Task 1 – What I learned

- `document` represents the HTML page.
- JavaScript can access and change HTML elements using `document`.
- The DOM allows us to make websites interactive.

### Task 2 – Working with myList

- `getElementById("myList")` selects the HTML list.
- `createElement("li")` creates a new list item.
- `appendChild()` adds the new item to the list.

### Task 3 – Form Element

- The `<form>` element collects user input.
- The `action` and `method` properties control how and where form data is submitted.
- The `elements` property gives access to input fields.
- The `reset()` method resets form fields to their default values.
- The `noValidate` property disables automatic form validation.
